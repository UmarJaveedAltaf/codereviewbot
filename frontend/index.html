// WHAT IT CATCHES

Every layer of your pull request, analyzed in parallel.

AST Parsing

Deep structural analysis beyond grep. Detects bare excepts, mutable default arguments, shadowed builtins, and unreachable branches that diff-only reviews miss entirely.

ChromaDB stores every past review as an embedding. Similar code surfaces related findings instantly — so the bot learns your codebase's recurring patterns over time.

// QUICK SETUP

Three steps from zero to automated code review.

[STEP 01 / 03]
Clone & configure
$ git clone https://github.com/UmarJaveedAltaf/codereviewbot
$ cd codereviewbot
$ cp .env.example .env # add GOOGLE_API_KEY + GITHUB_TOKEN
$ docker-compose up -d [OK] server listening on :8000

One docker-compose up starts the webhook server, ChromaDB vector store, and Streamlit dashboard together. No manual installs required.

[STEP 02 / 03]
Register the webhook
# GitHub → repo → Settings → Webhooks → Add webhook
Payload URL https://<your-host>:8000/webhook
Content type application/json Secret $GITHUB_WEBHOOK_SECRET Events Pull requests
[OK] webhook verified by GitHub [OK] HMAC-SHA256 signature valid

The bot validates every payload with an HMAC-SHA256 signature check — no unauthenticated requests get through. Copy the secret from your .env into the GitHub webhook form.

[STEP 03 / 03]
Open a pull request
# push a branch — the bot fires automatically
$ git push origin feature/my-change
[OK] webhook received — PR #48 [OK] Gemini review posted (11.2s) [OK] Slack: #dev-reviews notified

Inline comments appear on the diff within seconds. CRITICAL findings surface immediately; warnings and suggestions guide the author without blocking the flow.
